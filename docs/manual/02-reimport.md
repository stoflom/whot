# Chapter 2 — Re-importing a film roll

Status: outline — writing not started

*What you will learn: how to bring a roll in a second time — after you have
added pictures to it, or after a better import run — without losing the
naming work you have already done.*

## 2.1 When to re-import

- Typical reasons: pictures were added to an already-imported folder, the
  first import ran on a machine without the face finder, or you want the
  same folder re-examined with better settings.
- What re-import does in one sentence: it looks at the pictures again and
  matches what it finds against what it found last time, so your accepted
  work stays.

## 2.2 How to re-import

1. Start the import the same way as the first time (Ch. 1.1) and choose the
   re-import option.
2. Watch the progress as usual.
3. When it is done, review the newly found faces — they arrive pending, the
   same way as a first import.

## 2.3 What changes and what is protected

- Protected: every face you have accepted or rejected stays exactly as you
  left it.
- Refreshed: faces that were still pending get compared against the new
  look at the pictures; matching faces are re-linked so pending work is not
  orphaned.
- New pictures in the same folder import as usual.
- Good to know: re-importing the same roll twice does not create duplicates
  — the second run recognises its own earlier work.

## 2.4 Checking the result

- How to see what changed: the newly pending faces appear under the `New`
  filter; the import summary names what it reworked.
- If something looks wrong: what to check first (the re-import only touched
  pending faces; your accepted faces were never in its way).
