# WhoT — User Manual

Status: written — awaiting review (design: `docs/manual-design.md`)

WhoT looks at your photographs, finds the faces in them, and helps you put
names to those faces. Once a face has a name, WhoT can share that knowledge
with the other programs you use to manage your pictures.

This manual is for everyday use. It does not cover installation or
programming — see `README.md` in the project folder for those.

## How to read this manual

Read Chapter 0 once; it explains the few words the manual uses. After that,
every chapter stands on its own: open the one that matches what you want to
do, follow the numbered steps, done.

## Good to know from the start

- Nothing in WhoT changes your photographs. WhoT keeps its own record of
  faces and names; your picture files stay where they are.
- Work is saved as you go — there is no save button and nothing to lose by
  closing the window.
- A few actions cannot be undone; wherever that is the case, the manual
  says so in the step itself.
